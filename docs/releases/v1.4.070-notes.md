# vm2api v1.4.070

- 修复 cli-node 2.1.321 的文件监看崩溃：filename 为 undefined 或 null 时完整刷新配置，不再调用缺失值的 toString()。
- 同步更新 amd64 CLI 与 ARM64 嵌入源码的精确 SHA256 pin，修复 v1.4.068/v1.4.069 的 ARM64 构建哈希不匹配。
- 基于已发布 v1.4.069，保留该版控制面行为；其他 kernel/helper/CRAG payload 字节均不变。
- 本次不增加重试、不更改内存限制；kin-59 的独立 OOM 问题不在修复范围。

## Upgrade

使用 v1.4.070 的完整 payload 或多架构镜像。已有运行中槽位需通过面板排空并重启所选 Claude 槽位，然后检查实际运行 CLI 哈希和 ready slots；仅下载附件不会替换现有进程。不重建容器，不覆盖账号、授权、routing.json、vms、data 或 .env。
