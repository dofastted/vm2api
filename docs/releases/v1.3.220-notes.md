> 修原生 CLI CCH 误扫整段 JSON、把 messages 里 billing 示例当真实计费头，导致多轮历史被改写、缓存前缀失效。

本版让 Node 与原生 CLI 只投影/赋值首个 canonical system billing block；messages、工具结果与后续 system 示例不再被改写。`deploy/payload.json` 钉住已在线验证的 cli-node；并为 1.3.198–1.3.219 提供 `scripts/fix-cli-cch.mjs` 最小历史热修。

## Bug 修复

- 修复原生 CLI CCH 误改写历史消息中的 billing 示例，恢复多轮 prompt-cache 前缀稳定（#692）
- Node 侧同步只认首个 canonical system billing，与原生 CLI 行为对齐（#692）

## 升级指南

- **新装 / 跟 tip**：更新 Node 控制面后执行 **`npm run fetch:payload`**（或等价方式）换上新 **cli-node** pin，并回收 Anthropic CLI 子进程；**仅更新 Node 不够**
- **历史 1.3.198–1.3.219**：须显式跑 **`scripts/fix-cli-cch.mjs`**（见 `docs/cli-cch-hotfix.md`）；源码归档不可变，补丁只换 CLI 模板/manifest
- **勿集群 sync、勿 recreate 容器**；drain 后只换 CLI 模板/slot-bin 并回收子进程；排除 OpenAI 槽
- 不要覆盖 `routing.json`、`vms/`、`data/`、`.env`
