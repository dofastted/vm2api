# 主动查询官方额度

Claude 槽位的列表、机架、用量弹窗和详情页额度区提供「主动查询」。管理员可查询所有槽位，普通用户只可查询本人槽位，super 不开放此操作。没有凭证或仅有推理权限的凭证时按钮禁用。

`POST /api/panel/vms/:id/usage/query` 通过现有槽位 OAuth transport 和绑定出口调用官方额度链路（usage 与 profile），显式关闭 Fable 模型探测。有效的新额度写入现有账号额度存储，清除额度读取缓存后刷新列表及详情。同一槽位的并发点击共享一次进行中的请求，完成后再次点击会重新查询。

沿用官方额度解析规则，包括只有周额度而没有 5 小时窗口的有效结果。官方 429 会保存并遵守既有退避时间；凭证缺少权限、网络失败及不完整结果明确报错，不以历史额度冒充查询成功。套餐信息沿用现有 probe 与额度入库规则，本功能不增加独立套餐识别链路。

成功返回 `ok: true` 及 `data.vm_id`、`source`、`probed_at`、`five_hour`、`seven_day`、`seven_day_oi`。错误使用标准 `ok: false`、`error.code` 和 `error.message`：404 槽位不存在或不属于本人；400 凭证或平台不支持；403 角色无权限；429 官方限流；502 官方查询失败。
